---
title: Reservation
---

The `Reservation` class represents a Slurm advance reservation, which
pre-allocates nodes or CPUs for a specific time window. Reservations are used
for maintenance windows or guaranteed access for specific users and accounts.
Use [`Reservations.load`][pyslurm.Reservations.load] to fetch all reservations.
